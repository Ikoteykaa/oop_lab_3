# Lab-3 — Конструктори, перевантаження (overloading)

Консольний застосунок мовою C# для обліку відеоігор. Практична робота №3 з дисципліни «Об'єктно-орієнтоване програмування» (ХАІ, кафедра інженерії програмного забезпечення).

Програма є доопрацюванням Lab-2: до класу додано перевантажені конструктори та перевантажений метод, а при додаванні гри об'єкт створюється випадково обраним конструктором.

**Автор:** Кіндєєва Анастасія Олександрівна, група 621п

## Мета роботи

- створювати конструктор класу;
- перевантажувати конструктор класу;
- перевантажувати методи класу, які реалізують його поведінку.

## Що є в програмі

### Файли проєкту

| Файл | Призначення |
|---|---|
| `Program.cs` | Консольне меню, введення даних, створення об'єктів різними конструкторами, пошук, видалення, обробка винятків |
| `VideoGames.cs` | Клас «Відеогра»: поля, властивості, конструктори, методи |
| `GameGenre.cs` | Перелічення (`enum`) жанрів гри |

### Конструктори класу `VideoGames`

| № | Конструктор | Особливості |
|---|---|---|
| 1 | `VideoGames()` | Без параметрів: ініціалізує поля значеннями за замовчуванням (назва «Без назви», жанр `Action`, рейтинг 0, дата 01.01.2000, ціна 1) |
| 2 | `VideoGames(string name, GameGenre genre)` | Приймає назву та жанр, решту значень передає в конструктор №3 через `this(...)` |
| 3 | `VideoGames(string name, GameGenre genre, double rating, DateOnly releaseYear, double price)` | Повний: встановлює всі характеристики через властивості з перевіркою |

Кожен конструктор виводить повідомлення `[Система]` про те, який саме спрацював. Конструктор №2 викликає №3 через `this(...)`, тому повідомлення з'являються в порядку: спочатку «з УСІМА параметрами», потім «з 2 параметрами (використано this())».

### Перевантажений метод

| Метод | Опис |
|---|---|
| `StartGame()` | Додає 1 гравця |
| `StartGame(int playersToAdd)` | Додає вказану кількість гравців (якщо значення більше 0) |
| `ExitGame()` | Віднімає 1 гравця, повертає `true`/`false` |

Обидві версії `StartGame` змінюють лічильник через private-метод `ChangePlayerCount(int delta)`.

### Властивості (збережені з Lab-2)

Усі поля private, доступ через public-властивості з валідацією: `Name` (2–50 символів), `Genre` (значення з `enum`), `Rating` (0–5), `ReleaseYear` (не в майбутньому), `Price` (> 0). Додатково: автовластивість `Publisher` (за замовчуванням `"Unknown"`), `CountPlayers { get; private set; }` та обчислювальна `IsTopTier` (`Rating >= 4.5` і `CountPlayers > 0`).

### Меню програми

На старті користувач вводить `N` — максимальну кількість ігор (N > 0).

```
1 - Додати об'єкт (Гру)
2 - Переглянути всі об'єкти
3 - Знайти об'єкт
4 - Продемонструвати поведінку
5 - Видалити об'єкт
0 - Вийти з програми
```

- **Додати** — після введення даних об'єкт створюється **випадково обраним** конструктором (`Random.Next(1, 4)`); користувач бачить повідомлення, який конструктор спрацював. Якщо конструктор не приймає всі значення, решта встановлюється через властивості.
- **Переглянути** — таблиця з усіма іграми (номер, назва, жанр, рейтинг, дата, ціна, кількість гравців, `TopTier`).
- **Знайти** — пошук за жанром або роком випуску.
- **Продемонструвати поведінку** — підменю для вибраної гри:
  1. запустити гру (+1 гравець) — `StartGame()`;
  2. запустити гру (додати декілька гравців) — перевантажений `StartGame(int)`;
  3. вийти з гри (−1 гравець) — `ExitGame()`;
  4. змінити рейтинг.
- **Видалити** — за номером у таблиці або всі ігри певного жанру.
- **Вийти** — завершення програми.

### Обробка помилок

Введення даних обгорнуто в `try-catch` (`ArgumentOutOfRangeException`, `ArgumentException`, `FormatException`, `Exception`). Завдяки валідації у властивостях та в повному конструкторі некоректні значення відхиляються незалежно від того, який конструктор було обрано.
